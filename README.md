# Desharhozam

Статическая читалка: FB2, EPUB, PDF, DOCX и TXT.

Распакуйте архив и загрузите его содержимое в корень репозитория GitHub. index.html должен находиться в корне. Сборка и npm не нужны.

Для GitHub Pages выберите публикацию из ветки main, папка / (root).

Локальный запуск: python3 -m http.server 8000, затем http://localhost:8000.

Книги и заметки хранятся в браузере на конкретном устройстве и адресе сайта. При смене адреса автоматически не переносятся. PDF требует загрузки PDF.js из сети при первом использовании.

Светлая тема включается при первом открытии новой версии. Далее выбор темы сохраняется. Обложки переключаются на список. Меню цитат открывается выделением текста; обычное нажатие не открывает его.
